# JavaScript In-Depth 🚀

A rigorous workspace dedicated to mastering core JavaScript engineering principles by exploring language internals, primitive behaviors, built-in data types, and fundamental data structures from scratch. 

## What's Inside

* **Language Primitives & Internals:** Deep exploration of data types (`Number`, `Boolean`, `NaN`), lexical grammar, and internal operations.
* **Data Structures:** Implementing and analyzing core data structures using modern JavaScript.
* **Modular Exercises:** Clean, isolated scripts demonstrating edge cases and underlying mechanics.

## Current File Structure

| File / Folder | Description |
| :--- | :--- |
| `Boolean.js` | Boolean primitives, wrapper objects, and instance method mechanics. |
| `NaN.js` | Edge-case analysis of `NaN`, type coercion quirks, and comparisons. |
| `Number.js` | Number data type representation, precision limits, and utility functions. |
| `types.js` | Foundational script exploring primitive typing behavior. |
| `index.html` | Interactive test environment and UI runner for code execution. |

## Goal

Built to systematically master JavaScript fundamentals and architecture principles.
